GCP Audit Logging Notice

Operations that need to be enabled (Data Access Logs)

Writing or overwriting entities in Datastore uses the Commit API (under google.datastore.v1.Datastore.Commit). To log these actions:

  1. Go to the GCP Console.
  2. Navigate to IAM & Admin > Audit Logs.
  3. Select the Cloud Datastore API from the list of services.
  4. Check the Data Write (for creations, updates, overwrites, and deletes) and/or Data Read (for lookups and queries) audit log types and save.
