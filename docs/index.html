Overview

The GCP Infrastructure Manager is a professional browser-based console designed to streamline schema audits, synchronized schema migration, query automation copy operations, and Cloud Datastore data sync between Google Cloud Platform environments.

BigQuery Schema Auditing

Perform side-by-side schema analysis to view differences in datasets across project IDs. Sync changes incrementally or run a full dataset replication.

Scheduled Query Copier

Quickly retrieve scheduled queries from target regions and clone their sql parameters, execution routines, and destination tables to target GCP projects.

Datastore Data Sync

Scan entities using complex property filters, preview modifications in real-time, execute substring find-and-replace alterations, and push bulk data changes.

Zero Infrastructure

Runs entirely client-side using native GCP REST API endpoints under your direct IAM token credentials. Secure, lightweight, and extremely transparent.

Authentication

GCP Infrastructure Manager requires a valid OAuth 2.0 access token corresponding to a user or service account with the required IAM access roles.

1
Generate Access Token

Ensure you have the Google Cloud CLI (`gcloud`) installed, authenticated, and configured. Run the following command in your terminal to print a temporary OAuth2 token:

gcloud auth print-access-token
2
Authenticate Console

Paste the generated token into the authentication form in the web app and click **Verify Token**. The app will validate the token against Google OAuth endpoints, retrieve the associated user email, and populate the project dropdown configurations.

Under the Hood: Schema Verification Log

When you run a dataset comparison, differences are classified per field and row using visual badges:

Status Badge Meaning / Implication Resolution Action
ADDED The column exists in the Source table but is missing in the Target. Sync will **patch** the target schema to insert this column safely without deleting data.
REMOVED The column exists in the Target table but is missing in the Source. No destructive actions are taken. GCP BigQuery does not allow deleting columns via console schema patching.
MODIFIED The column exists in both tables, but attributes (data type or mode) differ. Review carefully. Sync will attempt to patch, but incompatible type changes will throw validation warnings.

Cross-Location Handling

The transfer config utilizes the GCP Data Transfer Service API. You can specify a source location (e.g., `us`) and a target location (e.g., `eu`). During copy, project identifiers inside the query parameters and destination tables are modified if they reference the source project ID, replacing them dynamically with target identifiers.

Custom Filter Mappings

Scan the source datastore by adding custom matching parameters. Filters translate directly to datastore structured JSON queries:

  • EQUAL / LESS_THAN / GREATER_THAN: Query properties against string, integer, or boolean values.
  • HAS_ANCESTOR: Limits scans to entities belonging to a specific root entity path key.

Find & Replace during Copy

You can replace parts of string property values dynamically during migration. For example, replace source domain configurations `https://api.source.com` with target configurations `https://api.target.com`.

Sweep Secret Scanner

Sweep is a lightweight, 100% client-side security scanner. It runs inside your browser to parse code blocks, configurations, or environment setups for credentials, keys, and connection strings before they are pasted into external interfaces.

Optimization & Performance

Sweep is designed to audit files with tens of thousands of lines in real-time without locking the browser UI thread:

  • O(log N) Line Resolution: Precomputes line offsets once. Finding a match's line number is resolved using a binary search rather than string scanning.
  • Debounced Non-Blocking Loop: Adjusts delay dynamically (up to 600ms for large pastes) so scanning waits for typing to pause.
  • Coverage Checker: Range sorting and prefix-max-end array checks prune overlapping matches instantly.
Shannon Entropy Analysis

Measures character randomness to detect un-patterned credentials (e.g., database passwords or tokens). The Shannon Entropy of a string is calculated as:

\[H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)\]

Where \(P(x_i)\) represents the probability frequency of character \(x_i\) in the string. If the resulting value exceeds the **4.3 bits/character** threshold, it is flagged as a potential secret. Obvious placeholders, UUID formats, and hash signatures are skipped.

Active Signature Rules

High-confidence regular expressions identify known token formats immediately:

  • AWS: Access Keys (`AKIA` prefixes) and Secret Access Keys.
  • Google & Firebase: Web API keys (`AIza`), Client Secrets (`GOCSPX`), and private key JSON blocks.
  • LLM Providers: OpenAI (`sk-`) and Anthropic (`sk-ant-`) API tokens.
  • GitHub / NPM / Slack / Stripe: Vendor personal and oauth integration tokens.
  • Twilio / Heroku / SendGrid / DO: Platform API keys and connection SIDs.
  • Credentials: JWT blocks, database URI credentials, and URL Basic Authentication patterns.
Heuristic Audit Logs

Informational logs flag suspicious lines that do not confirm a secret but warrant developer audit:

  • Named Fields: Variables like `password = "val"` where the value is too short to trigger entropy rules.
  • Private Subnets: References to local hostnames or private range IP addresses (`10.x.x.x`, `192.168.x.x`, etc.).
  • Concatenated Variables: Credentials constructed dynamically using string joins (`key = val1 + val2`).
  • Warning Tags: Development placeholders containing `TODO`, `FIXME`, or `HACK` near variables.
Redaction & Clipboard Logic

Sweep performs precise in-place string replacements instead of simple line-deletions. It isolates quoted subsegments, connection credentials, and authorization headers, inserting a specific placeholder (e.g. `AWS_ACCESS_KEY_ID_REDACTED`). This ensures the structure of the file remains completely valid, allowing it to be compiled or copy-pasted directly into configuration files.
