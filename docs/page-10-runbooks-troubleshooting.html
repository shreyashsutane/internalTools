01 Production Error Code Reference Matrix

Error Code Service Layer Trigger Condition Standard Recovery Procedure
401 MISSING_TOKEN Client Enclave No Authorization header supplied. Paste freshly generated token into Step 1.
403 UNTRUSTED_ORIGIN Cloud Functions Request origin not matching allowed origins. Ensure request originates from https://gcp-tools-portal.web.app.
413 PAYLOAD_TOO_LARGE Audit Engine An individual audit request or chunk exceeded its bounded transport size. Retry the operation. Large snapshots are normally compressed and split automatically; reduce the batch only if the bounded chunk limit is still exceeded.
429 RATE_LIMITED Security Gate Operator exceeded 120 req/min threshold. Wait 60 seconds for the sliding rate-limit window to reset.
