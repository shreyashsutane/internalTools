1. Explain It Like I'm 5: What Does This Tool Do?

The simplest analogy to understand what's happening

Imagine you have two houses in Google Cloud: House A (Source) and House B (Target).

You want to move furniture (your records and database rows) from House A to House B, or check if both rooms have matching blueprints.

Normally, doing this requires writing dangerous command-line scripts where one typo can wipe out your data.

✨ GCP Infrastructure Manager is your gentle moving assistant. It packs the furniture safely, inspects the new room first, and keeps an exact photo backup so you can unpack or undo anytime with 1 click!

1. Memory-Only Safety
Your access token lives only in your browser tab's RAM. It is never saved to a database or disk.
2. Read-Only by Default
Comparing schemas and scanning tables will never write, modify, or delete anything in Google Cloud.
3. 1-Click Rollback (Undo)
Every copy automatically records a backup in Audit Logs so you can restore your original data instantly.

2. 5-Minute "Zero-to-Hero" Quickstart

Everything you need to know from logging in to your first safe copy

1

Get Your Access Token

Open your computer's terminal or Google Cloud Shell and paste this command:

gcloud auth print-access-token

Copy the output starting with ya29.... It is a temporary 60-minute VIP pass.

2

Paste & Authenticate

Open GCP Infrastructure Manager and paste the token into the top box:

Click "Verify Token"

3

5. Plain-English "Jargon Buster"

Technical cloud words translated into everyday speech

Cloud Term Everyday Plain English Translation
GCP Project A company account or workspace folder in Google Cloud where services and databases live.
Cloud Datastore A fast NoSQL database built by Google for storing app records like user profiles and product catalogs.
Kind The table name or category of data (for example: Users, Orders, or Settings).
Entity A single row or record inside a Kind (e.g. one specific user profile).
Key / Name The unique ID badge or license plate for an entity so Google Cloud knows which record it is.
BigQuery Schema The structural blueprint of a table (which columns exist, whether they are text or numbers, and if they can be empty).
Dry Run A safe practice test! The system tests your copy in memory without actually writing anything to Google Cloud.
1-Click Revert The "Undo" button that restores the database back to its exact previous state using the automatic pre-copy backup.

6. Help! Something Went Wrong (Troubleshooting)

Direct answers to the most common beginner questions

🔴 It says "401 Unauthorized" or "Token Expired". What should I do?

Google Cloud access tokens automatically expire after 60 minutes for your safety.

Fix: Open your terminal, run gcloud auth print-access-token again, copy the fresh token, and paste it into the app.

🚫 It says "403 Forbidden" or "Permission Denied".

Your Google Cloud account has not been given permissions for that project yet.

Fix: Contact your GCP project administrator and ask them to grant your Google account:

  • roles/datastore.viewer (to view/read entities)
  • roles/datastore.user (to copy/write entities)
  • roles/bigquery.metadataViewer (to compare table schemas)
⚠️ Can this tool accidentally delete my source database?

Never. The source project is strictly read-only. It only inspects entities and prepares a copy; it has no ability or code to delete source entities.

⏪ What if I copied data with a typo or mistake? How do I undo it?

Click on "Audit History" (or open SuperAdmin Activity Logs). Look for your copy action and click the blue "1-Click Revert" button. The system will automatically restore the target database to its pre-copy state.
