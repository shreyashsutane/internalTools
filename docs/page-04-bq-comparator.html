01 Absolute Read-Only Enforcement

The BigQuery Schema Comparator contains zero DDL/DML modification routines. It issues solely metadata retrieval API calls to Google Cloud BigQuery: 

// Only GET requests are dispatched to metadata endpoints:
GET https://bigquery.googleapis.com/bigquery/v2/projects/{projectId}/datasets/{datasetId}/tables/{tableId}
Authorization: Bearer {token}

// Never dispatched: POST /tables, DELETE /tables, or PATCH /tables

02 BigQuery Scheduled Query Transfer

Moving recurring analytics jobs between projects previously required manual re-entry of SQL statements, parameters, schedule intervals, and destination tables. Our automated transfer engine reads transferConfigs and recreates them cleanly in the target environment with variable replacement.
