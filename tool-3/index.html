Client-Side Cryptographic Policy

This utility uses the browser's native **Web Crypto API**. All encryption and decryption operations are performed completely in memory on your local machine. Key derivations use **PBKDF2** with **SHA-256** and **100,000 iterations** for high strength. The data is secured using **AES-GCM (256-bit)** authenticated encryption. No key, password, or plain text is ever transmitted over the network.
